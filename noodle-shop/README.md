# ก๋วยเตี๋ยวน้องบ๊อบ

เกมทำก๋วยเตี๋ยวขาย เล่นคนเดียวในเบราว์เซอร์ ใช้โมเดลนักเรียนหญิงผมบ๊อบ ตากลม และกระโปรงกรมท่าจากต้นฉบับเดิม พร้อมแขนที่ขยับตามงานในครัว

## เปิดเล่น

แตก ZIP แล้วเปิด `index.html` ด้วย Chrome หรือ Edge รุ่นปัจจุบัน ไม่ต้องติดตั้งและไม่ต้องมีอินเทอร์เน็ต
กดเริ่มเกมเพื่อให้เบราว์เซอร์เปิดเสียง หากไม่ต้องการเสียงกดปุ่มเสียงด้านบน

- **เปิดร้าน 3 นาที**: เป้าหมาย 8 ชาม ทำให้ถูกออร์เดอร์เพื่อเก็บเงินและคอมโบ ลูกค้าที่รอนานหรือได้อาหารผิดจะทำให้เสียหัวใจ
- **ฝึกทำ**: ไม่จำกัดเวลา ลูกค้าไม่หมดความอดทน ไม่บันทึกสถิติ
- **ชมการทำอัตโนมัติ**: ตัวละครทำอาหารให้ดูวนไปเรื่อย ๆ ไม่บันทึกสถิติ กดกลับหน้าร้านเพื่อหยุด

## ทำก๋วยเตี๋ยว

1. อ่านใบออร์เดอร์: ชนิดเส้น น้ำซุป จำนวนลูกชิ้น และใส่/ไม่ใส่ผัก
2. เลือกเส้นเพื่อเริ่มลวก กดยกตะกร้าเมื่อเข็มอยู่ในแถบสีทอง จะได้เส้นสุกพอดีและทิปเพิ่ม
3. ตักน้ำซุปที่ลูกค้าสั่ง เติมลูกชิ้นตามจำนวนและผักถ้าสั่ง
4. กดเสิร์ฟ หากทำถูกจะได้เงินและทิป ถ้าหยิบผิด ล้างถ้วยแล้วเริ่มใหม่ได้ในราคา ฿3

ปุ่มลัด: 1 เส้นเล็ก, 2 เส้นใหญ่, 3 บะหมี่, 4 น้ำใส, 5 ต้มยำ, 6 ลูกชิ้น +1, 7 ผัก, Space ยกตะกร้า, Enter เสิร์ฟ, P พัก

ปุ่มพัก การเปิดวิธีเล่น/โมเดล และการสลับไปหน้าอื่นจะหยุดเวลา ลูกค้า และการลวกเส้น
สถิติรายได้สูงสุดเก็บในเบราว์เซอร์เมื่ออนุญาตให้ใช้พื้นที่เก็บข้อมูล

## โมเดลและแอนิเมชัน

- นักเรียนหญิงต้นฉบับ: ใบหน้า ผมบ๊อบ ชุดนักเรียน กระโปรงกรมท่า พร้อมหายใจ กระพริบตา และแขนทำงานตามขั้นตอน
- หม้อก๋วยเตี๋ยว: โลหะไล่แสง น้ำซุปเดือด เตาไฟ ไอน้ำ และตะกร้อลวก
- เส้น 3 ชนิด: เส้นเล็ก เส้นใหญ่ บะหมี่ พร้อมยก สะเด็ดน้ำ และลงถ้วย
- ถ้วย: ริมถ้วย ขอบลาย น้ำซุป เครื่อง และการเคลื่อนชามไปเสิร์ฟ
- ลูกชิ้น: เงา ไฮไลต์ และการเด้งเข้าถ้วยทีละลูกหรือ 3 ลูก
- เสียง: น้ำเดือด หยิบวัตถุดิบ ลวก ตักซุป เสิร์ฟ รับเงิน และลูกค้ามาถึง สร้างด้วย Web Audio ไม่ต้องโหลดไฟล์เสียง

กด **โมเดลวัตถุดิบ** เพื่อดูแบบเคลื่อนไหวในเกม มีไฟล์ SVG ของหม้อ เส้น ถ้วย และลูกชิ้นใน `assets/` สำหรับนำไปใช้ต่อ

## แก้โค้ด

- `template.html` โครงหน้า HTML
- `style.css` หน้าตาและการรองรับมือถือ
- `model.js` โมเดลตัวละครต้นฉบับที่ปรับแขนให้ทำอาหาร
- `game.js` ออร์เดอร์ การทำอาหาร คะแนน โหมดเล่นและปุ่มควบคุม
- `render.js` ฉาก โมเดลอาหาร และแอนิเมชัน Canvas 2D
- `audio.js` เสียงสังเคราะห์

หลังแก้ไฟล์ รวมเป็น HTML ใหม่ด้วย Node.js: `node build.cjs`
นำ `index.html` ขึ้นโฮสต์ไฟล์ static ได้ เกมไม่มีระบบสมาชิก เซิร์ฟเวอร์ หรือการเชื่อม TikTok

เวอร์ชันนี้ตรวจการทำออร์เดอร์ จับจังหวะ ลำดับขั้นตอน คอมโบ ความอดทน พักเกม โหมดฝึก และตัวอย่างอัตโนมัติ รวมถึงภาพในเบราว์เซอร์ขนาดคอมพิวเตอร์/มือถือ ยังไม่ได้ทดสอบโทรศัพท์จริง

## เวอร์ชันมือถือ

- ปรับจอเล็ก 320 พิกเซลขึ้นไป ปุ่มสัมผัสใหญ่ 44–77 พิกเซล และจัดกลุ่มตามขั้นตอน
- แนวตั้ง: ฉากอยู่ด้านบน ออร์เดอร์และเวลารอลูกค้าอยู่ใกล้ปุ่มทำอาหาร
- แนวนอน: ฉากอยู่ซ้าย ปุ่มอยู่ขวา หมุนจอแล้วจัดตำแหน่งให้อัตโนมัติ
- เพิ่มปุ่มวิธีเล่นบนแถบมือถือ ซ่อนปุ่มลัดคีย์บอร์ด และใช้ข้อความ แตะยกตะกร้า
- รองรับขอบเว้าหน้าจอและพื้นที่ปุ่มระบบของโทรศัพท์ โดยไม่ปิดการซูมของเบราว์เซอร์
- mobile.css เป็นไฟล์รูปแบบมือถือที่รวมอยู่ใน index.html แล้ว หากแก้โค้ดใช้ node build.cjs รวมใหม่

สำหรับการเปิดจากโทรศัพท์คนละเครื่อง ให้นำ index.html ไปวางบนโฮสต์ static แล้วเปิด URL ผ่าน Safari หรือ Chrome บนโทรศัพท์ ไฟล์ HTML ที่ดาวน์โหลดเป็นตัวเกม ไม่ใช่ลิงก์เว็บที่เผยแพร่แล้ว การดูตัวอย่างไฟล์ในแอปแชต/แอปจัดการไฟล์บางตัวอาจไม่รัน JavaScript

ตรวจหน้าจอจำลอง 320×568, 390×844 และแนวนอน 844×390 ในเบราว์เซอร์ รวมถึงการกดทำอาหารและเสิร์ฟจริงผ่านหน้าจอแล้ว ยังไม่ได้ทดสอบอุปกรณ์โทรศัพท์จริง
